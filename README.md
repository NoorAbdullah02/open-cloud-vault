## ✨ Features Deep-Dive

### 1. 🖥️ Multi-Platform Desktop Sync & System Tray (Windows, macOS, Linux)
* **System Tray Resident:** Minimizes cleanly to the Windows Notification Area, macOS Menu Bar, or Linux Tray with quick status badges.
* **Bi-directional Local Folder Sync (`~/NoorDrive`):** Creates an automatic sync folder in your user home directory. Any file saved to `~/NoorDrive` automatically uploads to the cloud; files on cloud sync back locally.
* **Dual-Side Responsive View:** On desktop and tablet screens, enjoy a Google Drive-style dual-pane layout with persistent navigation sidebar and multi-view file grid/list.

### 2. 📱 Native Mobile Integration (Android APK & iOS)
* **System Share Sheet Integration:** Select photos, 4K videos, or PDFs from **Google Photos**, **Gallery**, or **WhatsApp**, tap "Share to NOOR DRIVE", and upload instantly in the background.
* **1-Tap Camera Uploads:** Back up entire phone photo and video libraries with live upload metrics (speed in MB/s, progress percentage, ETA countdown).
* **High-Contrast Dark Mode & Theming:** Deep slate `#0F172A` navigation drawer with crisp `#F1F5F9` typography, adaptive icons, and selectable accent color themes.

### 3. 🔒 Secret Vault / Isolated Safe Folder
* **Biometric & PIN Quarantine:** Protect sensitive documents using Fingerprint / Face ID on mobile (`local_auth`) or a 6-digit cryptographic PIN on desktop and web.
* **Strict Listing Exclusion:** Quarantined items are strictly omitted from global search, recent file feeds, and root directory listings.
* **Automatic Idle Lock:** Auto-locks upon minimizing the app or after periods of inactivity.

### 4. 🎬 Cinema-Grade Media Players (HTTP 206 Range Streaming)
* **Smooth Video Seeking:** HTTP 206 Partial Content range requests allow instant scrubbing, fast-forwarding, and rewinding across 4K/1080p videos without waiting for the full file to download.
* **Floating Audio Player Dock:** Bottom dock audio player with playlist queue, waveform scrubbing, and background play.
* **Native Document Viewers:** Built-in PDF reader with zoom/page controls, plus native Word (`.docx`), PowerPoint (`.pptx`), and text previewers.
* **In-App ZIP Inspector:** Preview file trees inside `.zip` archives directly in the browser with single-file extraction.

### 5. 🌌 Interactive 3D Celestial Constellations (Three.js & Skia)
* **Web Dashboard:** Interactive Three.js particle cloud with dynamic constellation lines, mouse parallax tilt, and smooth dark/light transitions.
* **Mobile & Desktop:** Custom Skia-powered celestial constellation canvas rendering smoothly behind drive views.

### 6. 🌐 Zero-Install WebDAV Cloud Drive
* **Mount as Local Disk:** Access your entire vault directly in your OS file manager without running third-party sync software:
  - **Windows:** File Explorer → *Map Network Drive* → Drive `Z:` → URL: `https://drive.noor.is-a.dev/api/webdav`
  - **macOS:** Finder → *Go* → *Connect to Server* (`Cmd+K`) → `https://drive.noor.is-a.dev/api/webdav`
  - **Ubuntu / Linux:** Files → *Other Locations* → *Connect to Server* → `davs://drive.noor.is-a.dev/api/webdav`

### 7. 🔗 Google Drive-Style Public Sharing (60-Day Default)
* **Default 2-Month Expiry:** Shared links default to 60 days of validity so recipients can access them long after sharing.
* **Viewer & Editor Permissions:** Share single files or nested folders with read-only or collaborative upload permissions.
* **Direct Social Sharing:** 1-click sharing to WhatsApp, Telegram, Email, and dynamic QR Code generation for mobile scanning.

### 8. 🧹 Storage Cleaner & SHA-256 Duplicate Finder
* **Reclaim Space:** Built-in analyzer detects identical files using SHA-256 cryptographic hashes and lists largest files for quick batch cleanup.

## 💻 Local Setup & Development

### 1. Prerequisites
* **Node.js:** v20.x or v22.x LTS
* **npm:** v10.x+
* **Flutter SDK:** v3.27+ (for desktop & mobile development)
* **PostgreSQL:** Neon Serverless PostgreSQL account (free at [neon.tech](https://neon.tech))

### 2. Installation
```bash
# Clone the repository
git clone https://github.com/NoorAbdullah02/open-cloud-vault.git
cd open-cloud-vault

# Install workspace dependencies
npm install
```

### 3. Generate Telegram MTProto Session
```bash
# Run the interactive session generator
node scripts/telegram-auth.js
```
Enter your phone number and OTP code. Copy the generated `TELEGRAM_SESSION_STRING` into your `.env`.

### 4. Database Setup & Seeding
```bash
# Push schema to Neon PostgreSQL
npm run db:push

# Seed master owner account and storage providers
npm run db:seed
```

### 5. Running Web & API Locally
```bash
# Option A: Build once, then start the single unified server on port 3000 (Same as Render production)
npm run build
npm start

# Option B: Run separate watch servers for active development
npm run dev:api   # NestJS API -> http://localhost:4000/api
npm run dev:web   # Next.js Web -> http://localhost:3000

# Run the automated API unit tests
npm test
```

### 6. Running Flutter Mobile / Desktop Locally
```bash
cd apps/mobile

# Run widget tests
flutter test

# Run code analyzer
flutter analyze

# Launch on desktop (Linux / macOS / Windows)
flutter run -d linux   # or -d macos, -d windows, -d chrome
```

## ☁️ 100% Free Production Deployment (Render + Neon)

This repository includes [`render.yaml`](./render.yaml) to host both the Next.js frontend and NestJS API in **one single Free Render Web Service (`noor-cloud-vault`)**:

1. Fork or push this repository to your GitHub account.
2. In [Render Dashboard](https://dashboard.render.com), click **New +** → **Blueprint** → Select your repository.
3. Provide your environment variables (`DATABASE_URL`, `DRIVE_PASSCODE`, Telegram credentials, and `BREVO_API_KEY`).
4. Click **Apply** — your drive will be deployed and accessible worldwide!

## 🌐 Connecting Your Free Custom Domain (`drive.noor.is-a.dev`)

1. Submit a registration Pull Request on [is-a-dev/register](https://github.com/is-a-dev/register) targeting `noor-cloud-vault.onrender.com` (create `domains/drive.noor.json`).
2. In **Render Dashboard** → Select `noor-cloud-vault` → **Settings** → **Custom Domains**.
3. Add `drive.noor.is-a.dev` and save.
4. Once the PR is merged, Render automatically verifies the CNAME challenge and issues a free Let's Encrypt SSL certificate!

## 🛡️ Security & Privacy Architecture
* **Ephemeral Memory Streaming:** Uploaded files stream through memory buffers straight to Telegram's MTProto storage — zero user files reside permanently on the web server disk.
* **Argon2id Passcode Encryption:** Master passwords and vault PINs are hashed using memory-hard Argon2id.
* **Quarantined Secret Vault:** Isolated cryptographic quarantine with biometric device unlock.
* **Automated 24/7 Keep-Alive:** GitHub Actions cron keeps the free Render instance awake with 0 cold starts.
